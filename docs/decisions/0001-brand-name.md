# ADR-0001 — Бренд атауы

**Status:** ✅ ACCEPTED
**Date:** 2026-08-25

## Context
Студияға атау, домен және позициялау керек. Иесінде **`nureke.kz`** домені
бұрыннан бар. «Nureke» — иесінің есімінен шыққан құрметті форма
(`Нұр` + `-еке`), ал **«нұр» — жарық** деген мағына береді.

## Options Considered

| Нұсқа | + | − |
|---|---|---|
| **Nureke Digital** (`nureke.kz`) | Домен бар — шығын нөл, бүгін бастауға болады. Founder-led бренд ҚР-дағы B2B-де ең жақсы жұмыс істейді. «Нұр = жарық» → визуалды концепция дайын | Жеке есімге байланған — компанияны сату қиынырақ; EN-де оқылуы орташа |
| ARQA Studio | Бейтарап, халықаралық | Жаңа домен + жаңа бренд құру уақыты мен ақшасы |
| NRK Studio | Қысқа, EN-ге ыңғайлы | Мағынасыз аббревиатура, есте қалмайды |
| Екі бренд (жеке + компания) | Ең дұрыс ұзақ мерзімде | Ерте кезеңде екі брендті көтеру — ресурс шашырату |

## Decision
**Nureke Digital** · домен `nureke.kz` · founder-led позициялау.

Слоган (RU): **«Digital-системы, которые приносят деньги»**

## Reason
1. **Шығын нөл, кідіріс нөл.** Домен бар — бүгін деплой жасауға болады.
   Жаңа бренд іздеу 1-ші клиентті кешіктіреді, ал ол — басты мақсат.
2. **Founder-led — жаңа студияның ең күшті картасы.** Клиенттік кейс жоқ
   кезде адамдар компанияға емес, **адамға** сенеді. «Мен финтех платформа
   құрдым, міне коды» деген хабарлама «біз кәсіби студиямыз» дегеннен
   әлдеқайда жақсы сатады.
3. **Мағына дайын:** нұр = жарық → визуалды тіл (қара фон + алтын/янтарь
   акцент) бірден шығады, брендбукке ай жоғалтпаймыз.
4. Outbound-тың басты каналы (warm list, WhatsApp, Instagram) бәрібір
   жеке брендтен жүреді — атау соған сәйкес келеді.

## Consequences
- Сайттағы «About» бөлімі — жеке, бірінші жақтан жазылады. Бұл әлсіздік
  емес, саналы таңдау.
- Кодта `SITE` конфигі бір жерде (`src/content/site.ts`) — атау немесе
  домен өзгерсе, бір файл түзетіледі.
- **Ұзақ мерзімде:** команда 5+ адам болғанда немесе халықаралық нарыққа
  шыққанда бейтарап компания бренді қосылады, ал `nureke.kz` жеке
  бренд/блог ретінде қалады (лид көзі). Ол кезде ADR-0001b жазылады.

## Ескерту
Домен иелігі мен DNS-ті тексеру керек — деплой алдында.
