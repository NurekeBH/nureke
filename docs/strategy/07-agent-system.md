## SUMMARY

Барлық 12 агентті бірден іске қоспаймыз. Себебі: агент — токен шығыны,
ал нәтиже бермесе — таза шығын. Сондықтан **фазалы қосу** моделі.

**Қазіргі кезеңде БЕЛСЕНДІ: 2 агент.**

## TOKEN ECONOMY RULES

**RULE 1** — Барлық агент бір уақытта жұмыс істемейді. Максимум 2 параллель.

**RULE 2** — Ірі зерттеу/талдау алдында үш нәрсе жазылады:
```
GOAL:            не үшін керек
EXPECTED OUTPUT: қандай форматта, қанша бет
TOKEN BUDGET:    шамамен қанша
```

**RULE 3** — Зерттеу бір рет жасалады. Нәтиже `/docs/research`-та сақталады.
Қайталанған сұрақ келсе — алдымен `/docs` оқылады, интернет емес.

**RULE 4** — Әр агент шығысы қысқа, құрылымды:
```
SUMMARY  ·  KEY FINDINGS  ·  RECOMMENDATION  ·  NEXT ACTION
```

**RULE 5** — Шешім қабылданса — `/docs/decisions`-қа жазылады.
Бір мәселе екі рет талқыланбайды.

**RULE 6** — «10 агент қосайық» деген ұсыныс ешқашан жасалмайды.
Алдымен: осы нәтижені бар ресурспен алуға бола ма?

**RULE 7** — Код жазу алдында мақсат бір сөйлеммен айтылады.
«Әдемі болсын» — мақсат емес.

## АГЕНТ ШАҚЫРУ ЕРЕЖЕСІ

Агент шақырмас бұрын өзіңе сұрақ қой:

```
1. Бұл жұмысты Orchestrator өзі 5 минутта істей ала ма?  → ИӘ болса, өзі істейді
2. Бұл жұмыс терең, бөлек контекст талап ете ме?         → ЖОҚ болса, өзі істейді
3. Нәтиже /docs-та бар ма?                               → БАР болса, оқы, шақырма
```

Үшеуінен де өтсе ғана — агент шақырылады.
