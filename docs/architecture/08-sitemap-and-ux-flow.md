## HOME — блоктар реті (конверсия логикасымен)

| # | Блок | Мақсаты | Мазмұны |
|---|---|---|---|
| 1 | **Hero** | 5 секундта түсіндіру | H1: «Мы собираем digital-системы, которые приносят деньги» + подзаголовок + 2 CTA: `Обсудить проект` / `Рассчитать стоимость` |
| 2 | **Trust bar** | Дереу сенім | Стек логотиптері: Flutter · NestJS · Next.js · PostgreSQL · Telegram · Claude |
| 3 | **Проблема** | Танылу | 3 карточка: «Заявки теряются» · «Kaspi забирает маржу» · «Подрядчик пропал» |
| 4 | **Қызметтер** | Навигация | 6 карточка → әрқайсысы жеке бетке |
| 5 | **⭐ Адал позиция + risk reversal** | Кейстің орнына дәлел | «Кейсіміз жоқ» деп ашық айту + 4 тәуекелді азайту шарты + пилот ұсынысы |
| 6 | **Процесс** | Тәуекелді азайту | Discovery → Дизайн → Разработка → QA → Запуск → Поддержка |
| 7 | **Неге біз** | Дифференциация | 4 нақты факт (жалпы сөз емес) |
| 8 | **Пакеттер** | Баға сүзгісі | Starter / Growth / Platform + «-ден» баға |
| 9 | **FAQ** | Қарсылықты алдын алу | 6 сұрақ (баға, мерзім, код кімдікі, кепілдік, төлем, қолдау) |
| 10 | **Соңғы CTA** | Конверсия | Форма: Аты · WhatsApp · Не керек · Бюджет |

**Ережелер:**
- CTA беттің әр 1,5 экранында қайталанады
- Форма өрісі **4-тен аспайды** (әр қосымша өріс конверсияны ~7% түсіреді)
- Телефон нөмірі + WhatsApp батырмасы **әрқашан көрінеді** (sticky)
- Hero-да video/анимация жоқ — LCP маңызды

## SERVICE PAGE ШАБЛОНЫ (SEO + конверсия)

Әр қызмет беті бірдей құрылымда (шаблон = жылдамдық + SEO тұрақтылығы):

```
1. H1 + бір сөйлеммен уәде
2. «Это для вас, если...» — 4 нақты жағдай
3. Проблема → шығын (сандармен)
4. Не кіреді (checklist)
5. Как работаем (мерзім бойынша кестемен)
6. Тірі демо сілтемесі (кейс жоқ кезде — жалғыз шынайы дәлел)
7. Пакеттер + баға
8. FAQ (6 сұрақ) → FAQPage schema
9. CTA форма
```

## КОНВЕРСИЯ ЖОЛДАРЫ (3 түрлі ниет)

```
ЖОЛ 1 — «Мен не керегін білемін» (жоғары ниет)
Home → Service page → Форма → WhatsApp-та жауап → Discovery қоңырауы
Мақсат: 3 клик, 60 секунд

ЖОЛ 2 — «Қанша тұратынын білгім келеді» (баға ниеті)
Home → Calculator → 5 сұрақ → Аралық баға → «Нақты смета үшін контакт»
Мақсат: бағаны жасырмау — керісінше, өзіміз береміз және лид аламыз

ЖОЛ 3 — «Не керегін білмеймін» (белгісіз ниет)
Home → AI Consultant → 7 сұрақ → Project Summary + ұсынылатын шешім
     → PDF/сілтеме → лид CRM-ге
Мақсат: құндылық беру арқылы контакт алу
```

**Барлық жол бір нүктеге түседі:** `Lead` кестесі + Telegram push.

## LEAD FORM — минималды өрістер

```
Аты*              text
WhatsApp*         tel        ← міндетті, себебі негізгі канал осы
Не керек?         select     [AI-бот / Мобильді қосымша / Сайт / CRM / Білмеймін]
Бюджет            select     [<1 млн / 1–3 млн / 3–10 млн / >10 млн / Білмеймін]
                             ← «Білмеймін» болуы міндетті, әйтпесе форма тасталады
[honeypot]        hidden
```

Жіберілгеннен кейін: «Рахмет! 2 сағат ішінде WhatsApp-та жазамыз»
+ Telegram-ға дереу push + `nextActionAt = now + 2h`.

## МОБИЛЬДІ ПРИОРИТЕТ

ҚР-да трафиктің **75%+ мобильді**. Сондықтан:
- Дизайн mobile-first жасалады, десктоп — екінші
- Sticky WhatsApp батырмасы (оң төменгі бұрыш)
- Форма бір бағанда, ірі өрістер (min 48px биіктік)
- Кестелер мобильде карточкаға айналады
- Тест: iPhone SE (кіші экран) + орта Android
